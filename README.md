# Shivay Innovations Website

A responsive, single-page website built from the supplied Shivay Innovations portfolio PDF. It uses the extracted company logo and portfolio visuals, plus a purpose-created social media dashboard visual.

## Preview locally

1. Extract the ZIP folder if needed.
2. Open `index.html` in a modern browser.
3. For local development, you can also run a static server from this folder, for example:

   ```bash
   python -m http.server 8000
   ```

   Then visit `http://localhost:8000`.

## Before publishing

- Replace the contact placeholders with the official business phone / WhatsApp number and email address.
- Connect the enquiry form to an email endpoint, CRM, or form service. The current form is a front-end preview and does not send or store submissions.
- Confirm service availability, package prices, taxes, and payment milestones before publishing. Pricing on the page is presented as indicative starting estimates from the supplied portfolio.
- Add the official website domain and social profile links when available.
- The portfolio industry cards are explicitly presented as illustrative design directions, not completed-client case studies.

## Structure

- `index.html` — full responsive website and interactions
- `assets/` — logo and image assets used by the website
